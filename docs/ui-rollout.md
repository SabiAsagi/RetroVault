# 겜자취 UI 적용 현황

기준: 게임 위키·아카이브의 정보 탐색을 우선하고, 내 다락의 수집 재미와 친근한 표현을 더한다. 디자인 원본은 https://www.figma.com/design/lwGQeaTSYGSU4vNuIj2lW6 이다.

## 1차 기본 UI

- 겜자취 로고, 내 다락 명칭, 공통 색상·테마 선택기
- 홈: 검색, 게임·플랫폼·제작사·연대기 탐색, 실제 게임 데이터
- 게임 탐색: 기존 필터·정렬·목록/카드·페이지 이동 유지
- 게임 문서: 목차, 개요·시대 정보·설치 사양·리뷰·기본 정보·수정 제안
- Figma의 가상 게임 및 출처 예시는 실제 데이터로 취급하지 않는다.
- 실제 표지 이미지는 유지하고 표지가 없을 때만 카트리지 형태를 사용한다.
- 출처별 근거와 문서 수정 이력은 DB 기능이 아직 없으므로 검증된 기록처럼 표시하지 않는다.

## 다음 적용 순서

각 단계는 현재 기능 점검 → Figma PC·모바일 및 상태별 시안 → 코드 적용 → 미리보기 검증 순서로 진행한다. 각 단계에 블랙·화이트·레트로 테마를 포함한다.

1. 내 다락: 진열·목록·필터·그룹·정렬·공개 범위, 비어 있는 상태
2. 게임 담기·수정: 검색, 소장/플레이 기록, 선택 정보 접기, 저장·실패 피드백
3. 플랫폼·제작사: 목록과 상세 정보, 관련 게임 연결
4. 다락 구경·프로필: 공개 컬렉션과 개인 기록 구분, 친구·공유 흐름
5. 연대기: 연도 탐색, 확대·필터 및 모바일 사용성
6. 계정·친구·분석·업적: 로그인·가입·복구, 권한·비로그인 안내
7. 정보 추가·수정 제안 및 관리자: 검토 상태·오류·완료 안내

공통 테마가 적용되어도 위 화면들의 개별 UI 재설계가 완료된 것은 아니다. 기존 개인정보·약관 검토본의 운영 적용 전 확인 사항은 legal-launch.md에 따른다. Production 병합은 별도 진행한다.
