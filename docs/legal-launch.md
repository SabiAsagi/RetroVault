## 직접 확인한 인프라

Vercel 프로젝트 Storage 설정에서 Neon PostgreSQL `RetroVault_Database`와 공개 Blob `RetroVault_Photo`가 연결되어 있음을 확인했다. 둘 다 미국 워싱턴 D.C. / iad1이다. 저장소나 환경 변수는 변경하지 않았다. Blob은 공개 URL로 접근할 수 있어 컬렉션 비공개 설정과 파일 접근 제한을 구분해 안내한다. 파일 삭제 요청은 운영자가 Blob의 실제 파일도 별도로 확인·처리해야 한다.

## 구현한 범위

- 개인정보처리방침·약관 검토본과 문의 페이지, 스튜디오·연락처 Footer 연결
- 이메일 가입 API에서 연령 확인·필수 동의·정책 버전 검증
- 소셜 신규 가입에서 짧은 수명의 서명 쿠키 검증. 기존 연결 계정 로그인은 유지
- 생년월일을 수집하지 않는 자기 확인 방식이며, 성인 본인인증을 제공한다고 표현하지 않음
- 신규 컬렉션·그룹 비공개 기본값. 기존 항목 공개 범위는 변경하지 않음
- 메일을 보내지 않으면서 발송했다고 안내하던 복구 화면을 실제 문의 경로로 교체

## 운영 적용 전에 확정할 사항

1. 처리방침·약관의 실제 시행일을 확정하고 검토본 표시를 바꾼다. 변경 이력을 보관한다.
2. 문의 메일 처리 완료 후 30일 정리 기준을 운영자가 수행할 수 있는지 확인한다. 권리 요청 담당과 본인 확인·응답·삭제 절차를 정한다.
3. 계정 삭제 시 신고·관리자 로그 등 참조 관계와 업로드 파일까지 조사·삭제하는 운영 절차를 검증한다. 현재 자동 셀프 탈퇴나 자동 Blob 정리를 제공한다고 안내하지 않는다.
4. Vercel Hobby 플랜에 실제 적용되는 위탁 계약과 국외 이전 근거·고지 요건을 확인한다. 공개된 Vercel DPA는 적용 플랜 범위가 별도로 있어 계약이 체결되었다고 단정하지 않는다. Neon의 계약 주체·담당 연락처, 백업 삭제 주기 및 Gmail 문의 메일의 해외 처리도 확인한다.
5. 신규 소셜 계정에 대한 실제 OAuth 왕복과 콜백 도메인을 확인한다. 자동 테스트는 가입 우회·서명 위변조·만료를 검증하며 실제 외부 계정을 생성하지 않았다.
6. 현재 동의 확인 쿠키는 10분짜리 서명된 절차 확인용이다. 개인별 동의 이력을 DB에 영구 저장하는 기능은 아직 없으며, 장기 증빙을 제공한다고 표현하지 않는다. 운영 정책에 맞는 영구 동의 이력 설계는 별도 DB 변경으로 추가할 수 있다.
