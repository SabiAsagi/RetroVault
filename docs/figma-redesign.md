## 포함한 화면

- 홈 데스크톱 `3:645`, 모바일 `3:646`
- 게임 탐색 데스크톱 `3:647`
- 내 컬렉션 데스크톱 `3:648`
- 간단 컬렉션 추가 `3:649`

첫 화면은 게임 탐색과 진열장 예시에 집중한다. 최근 등록된 미래 출시작보다 시대별 탐험과 큐레이션을 앞에 배치한다. 장식용 0점·조회수·희귀도는 덜고 제목·플랫폼·연도를 우선한다. 소장은 기본 상태부터 고르고 상세 기록은 접힌 선택 영역으로 제안한다.

짙은 녹색·크림·민트 팔레트와 편집 가능한 카트리지 일러스트를 사용했다. 본문은 기존 Pretendard를 의도하되 Figma 환경에서 이용 가능하지 않아 Noto Sans KR로 대체했다. 픽셀 폰트는 짧은 브랜드 문구에만 사용했다. 실제 게임 커버 캡처나 평면화된 UI 이미지를 디자인 결과물에 넣지 않았으며 카트리지 일러스트는 네이티브 텍스트·도형으로 편집 가능하다. 실제 표지 에셋 연동은 별도 작업이다.

Code Connect와 기존 디자인 시스템은 없었다. Simple Design System의 버튼·검색 컴포넌트를 가져와 사용하고 RetroVault 팔레트 변수를 바인딩했다. Figma에서 새 레이아웃을 설계한 것이며 기존 웹 화면 전체가 이 시안으로 교체된 것은 아니다. 기본 비공개 정책과 문의·법적 안내 페이지는 웹 코드에도 반영했다.
